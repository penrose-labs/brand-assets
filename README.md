# Brand assets

Public logo files for Scope Health.

## Logos

| File | Use |
|---|---|
| `logos/scope-health-logo.svg` | Full logo (mark + wordmark), brand colours |
| `logos/scope-health-logo.png` | Full logo, 796×106 PNG |
| `logos/scope-health-logo-mono.svg` | Full logo, single colour via `currentColor` |
| `logos/scope-health-logo-white.svg` | Full logo, white, for dark backgrounds |
| `logos/scope-mark.svg` | Mark only, square 49×49 viewBox |
| `logos/scope-mark-tight.svg` | Mark only, cropped to its bounds (49×34) |
| `logos/scope-avatar.svg` | Vector avatar (preferred where SVG is accepted) |
| `logos/scope-avatar-256.webp` | 256×256 lossless WebP for logo grids |
